How to edit

Use the button above, or open app.diagrams.net and choose File → Open from → Device, then select NATS_Simulator_UML.drawio. The three page tabs are at the bottom. Double-click labels to edit; drag shapes to move them. Class compartments move together. For sub-elements inside a class, select the outer class first, then click the text you want to edit.

After editing, use File → Save as to keep a local .drawio copy. Export SVG or PNG for your report. Each box, label and connector is editable; the diagram is not an inserted screenshot.
